# Лабораторная работа 3

## Задание 1. Работа с синхронными и асинхронными методами

### Условие:

Реализовать функцию удаления нечетных чисел из одномерного массива натуральных чисел. После удаления одного из таких чисел выполнять паузу 1 секунду, затем удалять следующее. Все шаги показывать в консоли.

### Ключевые моменты реализации:

Использован async/await и промис с setTimeout для реализации неблокирующей паузы.

Для поиска первого нечетного элемента применён метод массива findIndex.

После каждого удаления выводится текущее состояние массива.

### Результат работы:

В консоли пошагово отображается процесс удаления элементов и финальный массив, содержащий только четные числа.

## Задание 2. Замыкания

### Условие:

Реализовать функцию, которая возвращает функцию. Вложенная функция должна печатать строку в консоль. Вызвать эти функции, показав принцип работы замыканий.

### Ключевые моменты реализации:

Функция createLogger принимает строку и возвращает вложенную функцию, которая выводит эту строку.

Вложенная функция сохраняет доступ к переменной message из внешнего контекста.

Созданы два независимых замыкания с разными сообщениями.

### Результат работы:

В консоли выводятся разные строки из замыканий, демонстрируя, что функция «помнит» окружение, в котором была создана.

## Задание 3. Декораторы класса

### Условие:

Создать декоратор, выполняющий блокировку изменения прототипа класса «Автомобиль». Проверить возможность добавления сторонних полей в объект после введения декоратора.

### Ключевые моменты реализации:

Декоратор SealPrototype вызывает Object.seal(constructor.prototype).

Это блокирует добавление новых методов или свойств в прототип класса.

Проверено: новый метод в прототип добавить нельзя, но в экземпляр класса можно добавить новое свойство (например, color).

### Результат работы:

Прототип класса «запечатан», но экземпляры можно расширять новыми полями.

## Задание 4. Декораторы метода

### Условие:

Реализовать декоратор метода, который преобразует возвращаемую строку в ЗАГЛАВНЫЕ буквы.

### Ключевые моменты реализации:

Декоратор Uppercase перехватывает оригинальный метод через descriptor.value.

После вызова метода результат проверяется на тип string и преобразуется методом toUpperCase().

Применено к методу info() класса CarTask4.

### Результат работы:

Метод возвращает строку, преобразованную полностью в заглавные буквы.
