
 ## Постановка задачи: 
 ### 1.Реализовать систему классов и интерфейсов для описания владельцев и транспортных средств. 
 ### 2.Продемонстрировать использование интерфейсов и классов. 
 ### 3.Реализовать наследование интерфейсов. 
 ### 4.Применить обобщения (generics) для создания хранилища транспортных средств. 
 ### 5.Организовать код с использованием пространства имён (namespace).  
 ### 6.Реализовать модульность и продемонстрировать работу с импортом из другого файла.
---
## Задание 1

### 1.Реализовать интерфейсы: Owner (владелец транспортного средства) Vehicle (транспортное средство) 2.Создать классы OwnerImpl и VehicleImpl с приватными полями, геттерами/сеттерами. 3.Реализовать метод printInfo() для вывода информации.

---
## Задание 2

### 1.Создать интерфейсы-наследники: Car (автомобиль) Motorbike (мотоцикл)

### 2.Добавить перечисления BodyType и CarClass. 3.Реализовать классы CarImpl и MotorbikeImpl с расширением метода printInfo().
---

## Задание 3

### 1.Реализовать обобщённый интерфейс VehicleStorage. 2.Создать класс VehicleStorageImpl. 3.Добавить возможность хранения транспортных средств разных типов.
---

## Задание 4

### 1.Объединить все интерфейсы и классы в пространство имён Transport. 2.Создавать объекты через Transport.*.
---

## Задание 5

 ### 1.Сделать пространство имён модулем (export namespace Transport). 2.Импортировать его в отдельный файл main.ts. 3.Создать объекты и вызвать методы из модуля.
 ---

Запуск проекта: tsc task1.ts task2.ts task3.ts task4.ts main.ts

Запустить любую задачу: node task1.js node task2.js node task3.js node task4.js node main.js
