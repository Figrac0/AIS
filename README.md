### Содержание  
6 мини-заданий на базовые структуры и типизацию в TypeScript.<br>

- **task1** — минимум из массива вещественных чисел.<br>
- **task2** — количество нулей в матрице целых чисел.<br>
- **task3** — кортеж из трёх строк и их конкатенация.<br>
- **task4** — перечисление типов принтеров + «человеческое» имя.<br>
- **task5** — обобщённая функция `createAndLog<T extends Pet>` для `Dog | Cat`.<br>
- **task6** — тип с использованием enum и кортежа; вывод объекта в JSON.<br>
